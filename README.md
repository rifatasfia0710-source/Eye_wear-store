#  Eye Wear Store - Web Application

## 📌 Project Overview

Eye Wear Store is a web-based application developed to manage and showcase eyewear products online. This system allows users to browse products, view details, and interact with the platform efficiently.

---

## 🚀 Features

* 🛍️ Product listing and details
* 🔍 Search functionality
* 👤 User authentication (Login & Registration)
* 🛒 Add to cart system
* 📦 Order management
* 🛠️ Admin panel for product management

---

## 🛠️ Technologies Used

* **Backend:** Laravel (PHP Framework)
* **Frontend:** HTML, CSS, JavaScript
* **Database:** MySQL
* **Version Control:** Git & GitHub
